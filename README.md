# JurisprudênciaIA MCP

**Projeto encerrado em 20 de novembro de 2026.**

A MinutaIA passou a exigir login para iniciar uma pesquisa no JurisprudênciaIA. O conector dependia do acesso sem login e deixou de funcionar com essa mudança. Em 20 de novembro, o serviço respondeu com HTTP 401 e `login_required` já na abertura da sessão, antes do envio da consulta.

O código e a [documentação anterior](https://github.com/brunoflma/jurisprudenciaia-mcp/blob/5269e5712436e87c644334f02b3c43bed8c54e6c/README.md) ficam disponíveis para consulta histórica.
